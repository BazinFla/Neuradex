## 🗺️ Roadmap & Upcoming Features
- [ ] **Favorite Models Pinning** : Star/pin favorite installed models to prioritize and display them at the top of the list.
- [ ] **Model Arena / Side-by-Side Comparison** : Dual-model benchmark comparing latency, tokens/sec, and response quality simultaneously.
- [ ] **Standardized LLM Benchmark ("Cinebench for AI")** : Long-term deterministic workload benchmark to stress-test compute throughput, TTFT, and sustained generation speed, outputting a reproducible hardware performance score.
- [ ] **Automated Hardware Benchmark** : 1-click profiling tool testing compute throughput and generating optimal configuration settings.
- [ ] **Connection Assistant & Snippet Generator** : Quick copy-paste configuration snippets for Continue.dev, OpenCode, Open WebUI, and Python SDKs.
- [ ] **Local OpenAI-Compatible Gateway & Multi-Provider Router** : Embedded lightweight reverse proxy exposing standard `/v1/chat/completions` and `/v1/models` to transparently route requests between local Ollama models and cloud providers (e.g., OpenRouter) with provider tagging for consuming tools (Continue.dev, Cursor, LibreChat).
- [ ] **Flatpak Packaging & AppStream Metadata** : Distribution via Flathub with XDG Desktop Portal integration.
